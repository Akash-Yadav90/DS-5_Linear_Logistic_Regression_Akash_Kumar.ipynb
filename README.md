# Linear & Logistic Regression

A machine learning project implementing Linear Regression and Logistic Regression
using Python and Scikit-learn.

## Overview

This project covers data preprocessing, model training, evaluation,
cross-validation, hyperparameter tuning, visualization, and model interpretation.

## Models

### Linear Regression
- Diabetes dataset
- Train-test split
- RMSE, MAE and R² evaluation
- Actual vs Predicted visualization
- Coefficient analysis
- 5-fold cross-validation

### Logistic Regression
- Breast Cancer Wisconsin dataset
- Feature scaling
- Accuracy, Precision, Recall and F1-score
- Confusion Matrix
- Classification Report
- GridSearchCV hyperparameter tuning
- Coefficient analysis
- Baseline vs Tuned comparison

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Results

### Linear Regression

- RMSE: 53.8534
- MAE: 42.7941
- R²: 0.4526

### Logistic Regression

- Baseline Accuracy: 98.25%
- Tuned Accuracy: 97.37%
- Best C: 0.1
